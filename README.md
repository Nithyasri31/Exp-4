# Exp - 4 HOSPITAL MANAGEMENT SYSTEM

# AIM:

To design and develop UML diagrams for a Hospital Management System. To represent system structure, workflow, and interactions between hospital modules and users.

# SRS (Procedure):

Step 1: Identify the main actors involved in the hospital system such as Patient, Doctor, Receptionist, Pharmacist, and Admin.

Step 2:Identify the major functionalities like patient registration, appointment booking, diagnosis, billing, laboratory testing, and medicine issuing.

Step 3:Create the Use Case Diagram to represent interactions between actors and the system.

Step 4:Design the Class Diagram to define classes, attributes, methods, and relationships.

Step 5:Develop the Activity Diagram to represent workflow with decision making, fork, and join operations.

Step 6:Construct the Sequence Diagram to show message flow between objects over time.

Step 7:Draw the Communication Diagram to represent object interactions using numbered messages.

Step 8:Design the Package Diagram to organize system modules into logical packages.

Step 9:Analyze all diagrams and verify proper relationships and process flow.
